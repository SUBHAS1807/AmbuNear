# AmbuNear Documentation

This package contains the initial planning documents for the AmbuNear
ambulance booking platform.

## Included Files

1.  `ARCHITECTURE.md` --- system architecture, technology stack, data
    flow and entities.
2.  `API_SPEC.md` --- planned REST API endpoints, authentication and
    response formats.
3.  `ROADMAP.md` --- development milestones from foundation to
    deployment.
4.  `REQUIREMENTS.md` --- functional, non-functional, assumptions and
    constraints.

## Project Concept

AmbuNear connects patients with nearby available ambulances.

Core flow:

``` text
Patient
   ↓
Find nearby ambulance
   ↓
Book ambulance
   ↓
Driver accepts
   ↓
Trip status updates
   ↓
Trip completed
```

## Planned Stack

-   React.js
-   Node.js
-   Express.js
-   MongoDB
-   Mongoose
-   JWT
-   Maps API
-   Git/GitHub
-   Render

These documents are the planning blueprint for the first AmbuNear MVP.
