# AmbuNear — Implementation Roadmap & Milestones

This roadmap guides the incremental, test-driven development of AmbuNear from foundation to full production readiness.

| Milestone | Stage | Key Deliverables |
| :--- | :--- | :--- |
| **Milestone 1** | Foundation | Project structure, Server & Client initialization, Database config, Health checks, Base layouts |
| **Milestone 2** | Authentication | User registration, Login, Password hashing, JWT token verification, RBAC middleware, Auth views |
| **Milestone 3** | Ambulance Fleet | Ambulance and Driver Mongoose models, Geospatial indexing, Fleet API, Driver onboarding |
| **Milestone 4** | Booking Workflow | Booking state machine, Driver accept/reject, Atomic locking, Dashboards for Patient & Driver |
| **Milestone 5** | Location & Geocoding | Browser Geolocation, Haversine formula, Interactive map with SVG/Canvas fallback, Radius search |
| **Milestone 6** | Admin Dashboard | System health metrics, User management, Driver & Ambulance verification tables, Audit records |
| **Milestone 7** | 20 UX Enhancements | Dark mode, Cookie banner, Site search, Back to top, Mobile drawer, Skeleton loaders, Copy buttons, Print styles, etc. |
| **Milestone 8** | Testing & Deployment | Unit/integration tests, Postman collection, Seeding scripts, Docker/Render/Vercel configs, Documentation |
